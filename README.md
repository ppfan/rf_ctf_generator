# SDR++ CTF: симульовані сигнали

`gen_ctf.py` генерує 10 IQ-записів (WAV, 16 біт, I/Q) під завдання CTF і ключ відповідей.

```
python3 gen_ctf.py                        # усі завдання -> out/
python3 gen_ctf.py --seed 7               # інша група = інші частоти/відповіді
python3 gen_ctf.py --tasks 9 --flag "CTF{KOD}" --wpm 8
python3 gen_ctf.py --tasks 1 --voice-wav my_voice.wav   # свій голос замість TTS
python3 gen_ctf.py --tasks 2 --lora-sf 12               # повільніші chirp-и
python3 gen_ctf.py --tasks 8 --jam-mode sweep           # свіп-перешкода замість шуму
python3 gen_ctf.py --tasks 6-8 --wide-fs 20e6           # менші файли для слабкого ПК
```

Потрібно: `python3`, `numpy`, `scipy`; для голосу в завданні 1 — `espeak-ng` (інакше DTMF-цифри).

## Відтворення в SDR++

1. Source → **File**, обрати `out/tNN_*.wav` (Float32 mode вимкнено).
2. Частота береться з імені файлу (`..._433500000Hz.wav`), файл крутиться по колу.
3. Ключ відповідей: `out/answers.md` — **не показувати курсантам** (екран стріму!).

## Що треба сказати курсантам перед завданням

| № | Файл | Підказка ведучого |
|---|------|-------------------|
| 1 | `t01_nfm` | Режим NFM, BW 12.5 кГц, слухати фразу |
| 2 | `t02_lora` | Збільшити FFT Rate (Display) до 60+ fps, щоб побачити chirp-и |
| 3 | `t03_fhss` | Корисні Max Hold / зменшити FFT size, щоб бачити сітку |
| 4 | `t04_ghosts` | Кожні 2 с «атенюатор» +5 dB: 0, 5, 10, 15, 20, 25 dB, потім знову 0 |
| 5 | `t05_weak` | Рівні в dBFS (у SDR++ немає калібрування в dBm) |
| 6–8 | `t06`–`t08` | 30 MS/s; файл 1–2 с у циклі |
| 9 | `t09_morse` | Режим CW (або USB), 10 WPM |
| 10 | `t10_fox` | Антена обертається 10°/с; «компас» на сусідній частоті: довгий імпульс = Північ, середні = 90/180/270°, короткі = кожні 10° |

## Обмеження симуляції

- Файл не реагує на налаштування Gain в SDR++: перевантаження в завданні 4 «прошите» сходинками атенюації.
- Рівні у dBFS. Шумова полиця −79 dBFS/бін при FFT 8192 (−40 dBFS загалом).
- Ширина перешкоди в завданні 8 = 50–72% від fs: при 30 MS/s це ~15–22 МГц. Для 50–100 МГц: `--tasks 8 --wide-fs 120e6` (~1 ГБ файл).
  Нагадайте: живий HackRF бачить максимум 20 МГц за раз, тому смугу 50–100 МГц треба переглядати частинами.
